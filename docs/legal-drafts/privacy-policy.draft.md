# 隱私權政策（草稿）

## 0. 本草稿的撰寫基礎

本草稿之資料清單**逐項對應 repository 的實際 schema 與程式碼**，
非通用範本。**未列入平台實際上並未蒐集的項目**（例如 IP 位址、
裝置指紋、廣告識別碼 —— 平台目前皆**未蒐集**）。

---

## 1. 適用範圍

1.1 本政策說明本平台就使用者個人資料之蒐集、處理與利用。

1.2 本平台之使用者包含**購買者**與**創作者**；同一使用者得同時具有兩種身分。

---

## 2. 蒐集之個人資料

### 2.1 帳號資料

| 項目 | 是否蒐集 | 儲存位置 |
| --- | --- | --- |
| 電子郵件位址 | **是** | `users.email` |
| 密碼 | **僅儲存雜湊值**（bcrypt），不儲存明文 | `users.password_hash` |
| 使用者身分別 | 是 | `users.role` |
| 帳號狀態與凍結紀錄 | 是（含凍結時間、操作者、原因） | `users.account_status` 等 |
| 註冊時間 | 是 | `users.created_at` |

> **現況揭露：平台於註冊時不蒐集使用者姓名。**
> 註冊僅需電子郵件位址與密碼（並選擇身分別）。表單上**沒有**姓名欄位，
> 姓名**不會**被送往伺服器、**不會**存入資料庫，**也不會**存放於使用者的瀏覽器。
>
> **`OWNER DECISION — DEC-06 = A`**（2026-08-27 Owner Decision Round 2 確認）
> **已於 2026-08-27 實作完成**（tracker `DEC-06`）：註冊表單之姓名欄位、
> 其必填驗證，以及 `localStorage` 的 `tp_display_name` 寫入**均已移除**，
> 且**未建立任何替代之姓名蒐集**（不新增暱稱、不由 Email 推導、不新增後端欄位）。
>
> 後端與資料庫**自始未曾**蒐集姓名 —— `POST /auth/register` 只接受
> email／password／role，`users` 表無 `name` 欄位。
>
> **殘留說明（非蒐集）：** `tp_display_name` 已**無任何寫入端**；
> 側邊欄之讀取與登出時之清除**刻意保留**，僅為讓既有瀏覽器內的舊值自然退場。

### 2.2 交易資料

* 訂單（品項、金額、數量、狀態、時間）
* 購買時之教材名稱與價格快照
* 訂單之付款期限與審核期限
* 履約之教材版本紀錄

### 2.3 付款相關資料

| 項目 | 說明 |
| --- | --- |
| 匯款申報資訊 | 銀行名稱、**帳號末四碼**、申報金額、申報匯款時間 |
| 付款憑證影像 | 使用者上傳之匯款證明圖片 |
| 平台查證之入帳事實 | 平台記錄之實際入帳時間 |
| 審核結果 | 核准／退件及退件原因 |

> **重要澄清：**
> * 平台**不蒐集完整銀行帳號**（資料庫層以 `^[0-9]{4}$` 限制僅接受四位數字）。
> * 平台**不蒐集**信用卡號、金融卡號或任何卡片資料 —— 平台**未串接任何金流服務**。
> * 平台**不蒐集**網路銀行帳號、密碼或任何金融機構登入憑證。
> * 平台**目前未蒐集**購買者之退款收款帳戶（刻意未蒐集，見《退款與取消政策》）。

### 2.4 申訴資料

* 申訴內容與往來紀錄
* 申訴狀態與處理歷程
* **使用者自行提供之外部證據**（匯款證明、交易明細等影像）

### 2.5 創作者資料

* 帳號資料（同 §2.1）
* 上架之教材及其描述、封面、試看素材與教材本體檔案
* 教材審核紀錄與權利審查紀錄
* 銷售與營收之統計資料

### 2.6 活動與稽核紀錄

平台保存操作稽核軌跡（`activity_logs`），內容包含：
操作者、操作者身分別、操作對象、動作類型、附帶說明與時間。

> **現況揭露：** 平台**未蒐集** IP 位址、瀏覽器 User-Agent、
> 裝置識別碼或地理位置。全資料庫 schema 均無對應欄位。

### 2.7 瀏覽器本機儲存

平台於使用者瀏覽器之 `localStorage` 與 Cookie 保存下列項目：

| 名稱 | 用途 | 是否傳送至伺服器 |
| --- | --- | --- |
| `tp_token` | 登入憑證 | 是（作為授權標頭） |
| `tp_role` | 介面顯示提示 | 否（僅供前端決定顯示哪個介面） |
| `tp_user_email` | 介面顯示 | 否 |
| `tp_display_name` | 側邊欄顯示名稱（**legacy：已無任何寫入端**，見 §2.1；僅既有瀏覽器可能殘留舊值，登出時清除） | 否 |

> **平台不進行瀏覽器端的產品行為事件蒐集。**
> 先前版本曾於瀏覽器 `localStorage` 累積產品操作事件（`tp_analytics_events`）；
> 該項蒐集**已於 2026-08-27 全面移除**（`DEC-08 = A`）——
> 事件記錄模組與其全部 5 個寫入點皆已刪除，**目前沒有任何寫入端**。
>
> 平台**未使用**任何第三方分析服務（無 Google Analytics、無 Sentry、無廣告追蹤），
> 亦**未**改以其他形式續行蒐集（無 sessionStorage、無 IndexedDB、無 Cookie、
> 未改送伺服器）。
>
> **殘留清除（非蒐集）：** 既有瀏覽器內可能仍留有舊值，
> 平台於使用者**登出時一併清除**該項目。此為協助舊資料退場，
> **不是繼續蒐集**。
>
> **此項與伺服器端稽核軌跡（`activity_logs`，見 §2.6）無關。**
> `DEC-08` 移除的是**瀏覽器端的產品行為事件蒐集**；
> 伺服器端之操作稽核與資安紀錄**維持不變**，兩者用途不同。

## 4. 非公開檔案之保護

4.1 下列檔案儲存於**非公開儲存空間**，須通過身分驗證與授權檢查方得存取：

* 付款憑證影像
* 申訴證據檔案
* 教材本體檔案

4.2 存取授權規則：

| 檔案 | 得存取者 |
| --- | --- |
| 付款憑證 | 平台管理員**或**該訂單之擁有者 |
| 申訴證據 | 平台管理員**或**該申訴之提出者 |
| 教材本體 | 平台管理員、該教材之創作者，以及具有效存取權限之購買者 |

4.3 平台不於任何 API 回應、記錄檔或前端狀態中揭露檔案之內部儲存識別碼
或雜湊值。

> 本政策**刻意不揭露**儲存實作路徑或內部結構。

>  **不得預設為永久保存**]`

## 7. 法律保留（Legal Hold）

7.1 部分資料於下列情形**暫不刪除**：進行中之消費爭議或申訴、
退款或補救案件處理中、侵權檢舉處理中、法定保存義務尚未屆滿，
或平台依法設定之法律保留。

7.2 平台就教材檔案設有**法律保留機制**，經標記之檔案在保留解除前不得刪除。

7.3 平台之檔案清理採**保守失敗（fail-closed）** 原則：
於無法確認是否可刪除時，**一律保留**。

> `[LAWYER REVIEW REQUIRED — 法律保留之要件、期間與解除條件]`
> **本草稿刻意未填入任何法律保留期限。**

## 8. 當事人權利

8.1 依個人資料保護法，當事人就其個人資料得行使查詢或請求閱覽、
請求製給複製本、請求補充或更正、請求停止蒐集處理或利用、
請求刪除等權利。**此等權利不得預先拋棄。**

8.2 **現況揭露（平台目前之實作程度）：**

| 權利 | 現況 |
| --- | --- |
| 查看 | **部分可行** —— 使用者可於平台查閱其帳號資訊、訂單、教材與申訴紀錄 |
| 更正 | **尚未提供自助功能** |
| 刪除 | **尚未提供** |
| 匯出（製給複製本） | **尚未提供** |
| 撤回同意 | **尚未提供** |

8.3 **Phase 1 方向：** 查看與更正將提供自助功能；刪除、匯出與撤回同意
先以人工受理方式處理。

> `[OWNER DECISION REQUIRED — O-21 / 人工受理之作業流程]`
>

> * **聯絡管道**已由 `DEC-LEGAL-07` 決定（見 §12）。

## 9. 帳號刪除

9.1 **平台目前未提供帳號刪除功能。**

9.2 **平台不承諾立即完全刪除。** 帳號刪除將受下列因素限制：

* 交易與稅務紀錄之法定保存義務
* 進行中之爭議、申訴或退款案件
* 法律保留
* 稽核軌跡之完整性要求

> `[LAWYER REVIEW REQUIRED — L-21 / 刪除使用者時，稽核紀錄中
>  「由誰執行」之紀錄應保留、假名化或匿名化]`
> `[OWNER DECISION REQUIRED — SCHEMA-02 / 帳號刪除之技術語意與流程]`
>
> **技術現況揭露：** 平台之稽核紀錄與使用者帳號存在關聯。若直接刪除帳號，
> 該使用者之全部歷史稽核紀錄將失去「由誰執行」之資訊，
> 與「不得改寫歷史稽核」之要求衝突。此為**尚未解決**之設計問題，
> 必須先完成保存期間之法律確認才能決定刪除語意。
